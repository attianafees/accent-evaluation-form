How to Evaluate Each Sentence

For each sentence, you will complete 5 steps. At each step:

  1. Listen to Audio A (baseline/reference) and Audio B (test)
  2. Mark errors on the transcript using codes: [P], [W], [S]
  3. Rate how Audio B compares to Audio A: -2 to +2

Error Codes

Code Error Type Examples
[P] PHONEME: Segmental phonetic error Retroflex as alveolar; Wrong aspiration; Nasalization error
[W] WORD/PROSODY: Suprasegmental error Wrong stress; Unnatural pitch; Clitic separation
[S] SCRIPT-INDUCED: From Perso-Arabic confusion Emphatic vowels; Pharyngealization; Arabic patterns
